# Kommindala Ramoji — Portfolio

A single-page developer portfolio showcasing full-stack web applications, technical skills, internships, and leadership experience.

**Live site:** https://my-portfolio-two-kappa-31.vercel.app/

## Tech Stack
- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- AOS (Animate On Scroll)
- EmailJS
- WebGL (Fluid Splash Cursor)

## Run Locally
```bash
npm install
npm run dev
npm run build
```

## Environment Variables
Create a `.env.local` file in the project root with your EmailJS credentials:
- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`
